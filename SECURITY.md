# Security Policy

Do not report vulnerabilities, credentials, customer data, or usable exploit details in a public Issue or pull request.

Use GitHub's [private vulnerability reporting](https://github.com/nest-boot/skills/security/advisories/new). If that option is unavailable, contact a repository maintainer privately through their GitHub profile before sharing sensitive details.

Include only the minimum information needed to investigate:

- affected skill and revision;
- impact and conditions required to trigger it;
- sanitized reproduction or evidence;
- suggested mitigation, if known.

Revoke or rotate any exposed credential immediately. Do not attach production logs or private project content to the report.
